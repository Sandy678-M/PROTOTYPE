# MediKiosk + LifeLink — Coded Prototype

## Run
1. Keep `index.html`, `styles.css`, and `app.js` in the same folder.
2. Open `index.html` in Chrome/Edge/Firefox.
3. No server or installation is required for this UI demo.

## Included prototype modules
- Patient registration, language selection and consent
- ABHA / patient identification
- AI clinical intake with voice/touch/text interaction simulation
- Adaptive clinical questions
- Medical document OCR workflow simulation
- Structured case summary
- Doctor dashboard and review/confirm workflow
- Medical timeline
- Optional LifeLink blood support + donor matching simulation
- Supporting AI Clinical Assistant
- Admin dashboard
- Technology/safety concepts represented in UI

## Important
This is a front-end demonstration prototype. The AI, OCR, speech-to-text, authentication, database, maps, ABDM/FHIR and donor matching are simulated; they are not connected to real healthcare systems or patient data.
